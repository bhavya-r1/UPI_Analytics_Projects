📌 Project Overview

How has India's Unified Payments Interface (UPI) evolved over time?

This project explores monthly UPI transaction data from July 2021 to November 2026 to analyse transaction growth, payment trends, financial-year performance and quarterly patterns.

The project follows an end-to-end analytics workflow, from data cleaning and validation to SQL-based analysis and interactive Power BI visualisation.

The objective: Transform raw transaction statistics into meaningful insights that help understand the growth and performance of India's digital payment ecosystem.

🎯 Business Objectives

- Measure overall UPI transaction volume and value.
- Analyse monthly transaction trends and growth patterns.
- Identify the top five months by transaction volume.
- Compare transaction performance across financial years.
- Evaluate transaction activity across financial quarters.
- Examine average transaction value and daily performance.
- Present key metrics through an interactive dashboard.

🔄 Project Workflow

01 — Data Preparation (Excel)

- Reviewed and cleaned the monthly transaction dataset.
- Checked missing values, duplicates and data consistency.
- Prepared calculated fields and financial-year classifications.

02 — Database Management (PostgreSQL)

- Created a dedicated database and transaction table.
- Imported the cleaned dataset.
- Verified record counts, date coverage and data integrity.

03 — SQL Analysis

Performed analytical queries using:

- Aggregate functions: SUM, AVG, MIN and MAX.
- Filtering and sorting: WHERE, ORDER BY and LIMIT.
- Date-based analysis and financial-year comparisons.
- GROUP BY and CASE statements.
- Window functions: LAG and RANK.
- Monthly, quarterly and yearly performance analysis.

04 — Dashboard Development (Power BI)

- Connected Power BI to PostgreSQL.
- Created KPI cards for key transaction metrics.
- Developed monthly transaction trend charts.
- Visualised top-performing months.
- Compared financial-year and quarterly performance.
- Added Financial Year and Month slicers for interactive exploration.

⚠️ Data Quality & Limitations

- The dataset contains monthly UPI-level transaction statistics.
- It does not include customer-level, merchant-level, bank-level or state-level transaction details.
- Certain months are missing from the supplied historical dataset; missing periods are not treated as zero transactions.
- November 2026 contains only four days of data and must be interpreted as a partial month.
- Growth comparisons are interpreted in the context of available historical records.

🔍 Key Insights & Results

The analysis revealed the following findings:

- Monthly Transaction Volume: Ranged from 2,008.07 million to 25,466 million transactions.
- Average Monthly Volume: Approximately 13,085 million transactions.
- Monthly Transaction Value: Ranged from ₹5,16,881 crore to ₹31,52,929 crore.
- Average Monthly Value: Approximately ₹18,33,435 crore.
- Average Daily Volume: Approximately 443 million transactions.
- Average Daily Value: Approximately ₹62,171 crore.

🏆 Project Results

- Analysed monthly UPI transaction trends across the available historical period.

📌 Important Observations

- UPI transaction activity varies considerably across months.
- Monthly and daily metrics provide different perspectives on payment activity.
- Missing historical months should not be interpreted as zero transactions.
- November 2026 contains only four days of data, so it requires separate consideration.
